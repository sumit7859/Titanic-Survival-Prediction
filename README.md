Titanic Survival Prediction
Project Overview
The Titanic Survival Prediction project is a Machine Learning project that predicts whether a passenger survived or did not survive the Titanic disaster based on passenger information.
This project uses historical Titanic passenger data to analyze survival patterns and build a predictive Machine Learning model.
Objectives

Analyze the Titanic passenger dataset.
Perform data cleaning and preprocessing.
Handle missing values.
Perform Exploratory Data Analysis (EDA).
Identify important survival factors.
Train a Machine Learning model.
Predict passenger survival.
